## 쉬운 관찰을 하자.

문제 조건의 $L_i \lt L_j \lt R_i \lt R_j$인 경우가 존재하지 않는다는 것은 포함관계 또는 서로 겹치는 부분이 없다는 것을 뜻한다. $L_i$와 $R_i$는 고유함으로 $N$쌍의 커플은 $N$쌍의 괄호로 해석할 수 있다. 또한 이는 트리로 해석할 수도 있다. 왜냐하면 dfs를 한다고 생각하자. 여는 괄호는 어떤 정점의 서브트리에 진입하는 것에, 닫는 괄호는 어떤 정점의 서브트리에서 탈출하는 것에 대응할 수 있기 때문이다.

## 이 문제의 정수, 포함 배제의 원리

여는 괄호와 닫는 괄호를 짝짓는 것을 매칭이라고 하자. 이때 여는 괄호는 닫는 괄호 이전에 등장하여야하고 옳은 매칭일 필요는 없다. 모든 여는 괄호와 닫는 괄호를 매칭한 하나의 경우를 시나리오라고 하자.

$L_i$와 $R_i$가 매칭되는 것을 사건 $A_i$라고 하자.

사건의 집합 $I$에 대하여 $M_I$를 오직 $I$의 사건이 발생하는 시나리오의 집합이라고 하자.
사건의 집합 $I$에 대하여 $S_I$를 적어도 $I$의 사건이 발생하는 시나리오의 집합이라고 하자.

이때 아래를 만족한다.
$S_I = \bigcap_{I \subset J \subset U} M_J$

목표는 $M_{\emptyset}$를 구하는 것이다.

```cpp
#include <bits/stdc++.h>

using namespace std;

using ll = long long;

const int MAXN = 3030;
const int mod = 1e9 + 7;

int N, DP[MAXN][MAXN], pv;
vector<pair<int, int>> LR;

void dfs(int u, int pn)
{
    pv++;
    vector<int> v;
    while(pv < N && LR[pv].second < LR[u].second) {
        v.push_back(pv);
        dfs(pv, pn+1);
    }
    for(int j = 1; j <= pn+1; j++) {
        ll X = j;
        ll Y = mod-1; // -1
        for(int i : v) {
            X = X * DP[i][j+1] % mod;
            Y = Y * DP[i][j] % mod;
        }
        DP[u][j] = (X+Y) % mod;
    }
}

int main()
{
    ios_base::sync_with_stdio(false); cin.tie(NULL);

    int T; cin >> T;
    while(T--) {
        cin >> N;
        LR.resize(N);
        for(auto& [l, r] : LR) cin >> l >> r;
        sort(LR.begin(), LR.end());

        pv = 0;
        ll ans = 1;
        while(pv < N) {
            int v = pv;
            dfs(pv, 0);
            ans = ans * DP[v][1] % mod;
        }

        cout << ans << "\n";
    }
}
```
